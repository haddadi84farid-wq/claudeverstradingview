MON DOSSIER TRADING — tout ce que je copie-colle est ici
=========================================================

CHAQUE JOUR
1. Double-clic sur DEMARRER (dossier du dessus, ou raccourci du bureau) -> attendre "PRET".
2. TradingView : PEPPERSTONE:XAUUSD en 15 min, indicateur "Plan XAUUSD — checklist achat / vente" present.
3. App Claude : Nouveau -> DESKTOP-H2QVCVL -> mode Manuel -> Ctrl+V -> Entree.
   (DEMARRER a deja copie le prompt 1_PROMPT_ANALYSE.)
4. J'attends le statut VERT (SIGNAL) ou l'alerte. Je verifie : R:R reel >= 1,5 au TP2, taille 0,01 lot.
   C'est moi qui passe l'ordre. Rien avant 07:00 UTC ni apres 18:00 UTC. Vendredi : a plat avant 22:30 Paris.

LES FICHIERS (ouvrir avec le Bloc-notes, Ctrl+A, Ctrl+C, puis coller)

                           puis Editeur Pine -> Ctrl+A, Ctrl+V, Ctrl+S.
- 3_PROMPT_SCALPING.txt  : plan de scalping 5 min (a completer : risque en euros).
- 4_BACKTEST_PINE.txt    : strategie de test (Editeur Pine -> nouveau -> coller -> Testeur de strategie).
- 5_PROMPT_REPLAY_DEBUT.txt : test sur une date passee. Remplir la ligne DATE en haut (ex. 2026-09-17),
                           coller dans une nouvelle session : Claude place le Replay a 09:00 Paris, fige le plan
                           et dessine. Ensuite c'est moi qui avance les bougies.
- 6_PROMPT_REPLAY_BILAN.txt : apres avoir avance (jusqu'a 18:00 ou 20:00 UTC) : Claude compte le resultat en R
                           et remplit le journal. En Replay, les alertes ne sonnent pas : je regarde le tableau.
- 7_PROMPT_REPLAY_SERIE.txt : LE PLUS SIMPLE pour tester plusieurs jours. Je mets les dates en haut, je colle
                           une seule fois dans une nouvelle session. Ensuite je tape seulement « bilan »

- 9_BACKTEST_APRES_ANNONCE.txt   : strategie de test, suivre la bougie d'annonce US sur le repli.
                           (a creer comme NOUVEAU script Strategie : Editeur Pine -> Creer nouveau -> Strategie)

- 11_BACKTEST_SCALP_OUVERTURE.txt : scalping 5 min, cassure de la 1re demi-heure Londres / New York, dans le sens de la tendance journaliere, frais inclus.
- 12_PROMPT_TENDANCE_SOIR.txt : LA METHODE QUI FONCTIONNE. Chaque soir apres 23:00 Paris, coller dans une session :
                           Claude dit pour l'or, l'argent et le petrole : rien / entrer / garder (nouveau stop) / sortir.
